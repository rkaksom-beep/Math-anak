# Math-anak — Assets for Math for Kids (MVP)

This repository contains SVG assets and hi-fi artboards for the Math-for-Kids MVP (replica) created during design specification. Files include mascots, icons, stickers, object sprites and 6 artboards (counting, compare, addition, subtraction, missing number, memory).

Structure:
- assets/svg/   — SVG icons, mascots, stickers, object sprites
- artboards/    — Hi-fi artboard SVGs for each mini-game

These files were added by an automation and are intended for import into Figma or direct use by developers/designers.
